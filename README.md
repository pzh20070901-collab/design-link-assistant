# LINK SHELF · 设计灵感导航

无依赖的中文设计网站收藏工具，包含 18 个初始链接。下载后直接打开 `index.html` 即可使用，也可以作为静态网站部署。

## 功能

- 多关键词搜索、分类筛选、收藏与名称排序。
- 添加、编辑、删除自定义网站，检查重复地址。
- JSON 备份导出与导入；导入会替换当前自定义网站和收藏，操作前会确认。
- 校验 HTTP/HTTPS 地址、备份格式与大小，过滤损坏的本地数据。
- 手机布局、键盘焦点和减少动画支持。

## 快捷键

- Ctrl / Command + K：聚焦搜索。
- 搜索中按上下箭头选择建议，Enter 打开选中网站，Escape 关闭建议。
- Ctrl / Command + Shift + I：选择备份文件（可能与浏览器快捷键冲突，也可使用导入按钮）。

## 数据说明

数据保存在当前浏览器的 localStorage，不会上传到 GitHub，也不提供跨设备同步。迁移浏览器、清理浏览数据或更换网站地址前请导出备份。浏览器禁用存储时仍可使用页面，但更改无法持久保存，页面会提示导出备份。

初始网站介绍和访问提示沿用原文件，未进行实时可访问性验证。

## 验证

安装 Playwright 及 Chromium 后运行 `node check.cjs`，检查搜索、添加、编辑、收藏、损坏存储恢复、地址校验和手机布局。软件本身不需要安装依赖。
